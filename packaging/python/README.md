# procage

Process sandboxing. On macOS it applies Seatbelt profiles through libsandbox
rather than by shelling out to the deprecated `/usr/bin/sandbox-exec`.

**Status:** under development. Version 0.0.1 only reserves the name for the
future Python bindings of the Rust crate [`procage`](https://crates.io/crates/procage)
and contains no API.
